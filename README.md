ython Tip Calculator 💰

A simple command-line tip calculator built using Python.

Features
Accepts the meal cost in dollars.
Accepts the desired tip percentage.
Calculates the tip amount.
Displays the result formatted to two decimal places.
Technologies Used
Python 3
How to Run
Install Python 3.
Download or clone this repository.
Open a terminal in the project directory.
Run:
python tip_calculator.py
Example
How much was the meal? $50.00
What percentage would you like to tip? 15%
Leave $7.50
Learning Outcomes

This project helped me practise Python functions, string manipulation, type conversion, user input, and formatted output
